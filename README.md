# 移动机器人手势识别与控制系统

基于 **Taobotics Gemini 移动机器人** 的人机交互项目。系统通过机器人前置 RGB-D 摄像头采集画面，将视频流发送至服务器；服务器使用 MediaPipe 识别手部关键点与手势，再将识别结果和图像位移信息返回机器人，由运动控制逻辑驱动机器人完成对应动作。

## 系统流程

1. RGB-D 摄像头采集实时画面。
2. ROS 将图像流发送到服务器。
3. MediaPipe 提取手部关键点并识别预设手势。
4. 服务端计算手势标记及手部相对位移。
5. 识别结果通过 ROS 返回机器人。
6. 机器人根据运动控制逻辑执行移动或转向动作。
