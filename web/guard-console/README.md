# 无执行器网关控制台

链路不稳定时阶段保持等待健康观测；后端明确报告关闭时显示已断开。连续约1秒新鲜观测只是手动 arm 的额外条件，任一过期重新计时，安全撤销仍即时，200/250ms限制不变。后端 envelope.error、状态/协议无效、HTTP及窗口初始化失败在只读诊断区显示。

独立只读原始控制键集合仅由真实 keydown/keyup 更新，不因状态 reset 清空，也绝不复制回命令队列；已观察仍按住的键阻止 arm。失焦/隐藏后标记物理状态未知并清意图，不能据此声称用户已松开。此增量仅静态及语法检查，未启服务或注入输入，真实非零链路仍待验证。

操作阶段只读显示连接未就绪、可取得会话、等待原始回中、输入已就绪或状态失效；条件不满足时显示明确原因。剩余秒数直接取自新鲜且属于本窗口的网关 lease_remaining_ms，不自行倒数或续租，未就绪为“—”。取会话在状态不新鲜、未聚焦、原始键未松开、忙、已有本地会话或停止锁存时禁用。阶段与文字仅变化时更新。

停止与释放保持可用并立即撤销本地结果。独立停止说明不会被轮询覆盖；失败或超时明确显示“策略停止未确认”。网关确认不代表物理停机验收，清锁存不会自动 arm。操作阶段增量仅经过语法与静态检查，真实方向输入链路仍待主线联调；未改动200/250ms时效、10秒租约、中立或会话保护。

总蓝图：M1 原型 → M2 监控 → M3 输入 → **M4 策略接入** → M5 设备 → M6 上线 → M7 验收。局部：API2 与固定 SSH → 独立控制台 → 初始化观察 → 用户真实键盘验证 → 后续独立执行器适配。蓝牙延期不阻塞主线。

在仓库根目录显式启动（网关路径必须使用本轮已编译版本）：

```powershell
python tools/serve_guard_console.py --robot-target handsfree@10.10.218.121 --jump-host llmemb-server --known-hosts C:/Users/yangq/.ssh/known_hosts --ssh-bind-address 10.10.218.207 --gateway /tmp/rs-m4-gateway-x69ry89q/build/robot_control_gateway --port 0
```

打开终端打印的 127.0.0.1 地址。只启动指定无执行器网关，固定运行上限 120 秒；不会自动重连、自动授权或续租。Ctrl+C 关闭 HTTP 和自有 SSH。断开后需手动重启服务，重新取得策略会话并回中。没有机器人运动写接口、ROS、串口或底盘驱动。

## 显式直连与热点地址

默认仍经 llmemb-server 中转。加 `--direct` 绕过跳板并禁用 SSH 配置中的代理；`--ssh-bind-address` 可省略，提供时绑定目标直连的本机 IPv4，中转模式仍只绑定跳板。直连保留 BatchMode、StrictHostKeyChecking=yes 和明确 known_hosts。

仅直连可加 `--host-key-alias 10.10.218.121`，用原来已信任的机器人身份记录核对切换 IP 后的主机密钥。别名只接受安全主机名/IPv4，不跳过校验，不自动 ssh-keyscan 或修改 known_hosts。若密钥不匹配，应停止并核实。热点地址与本机源地址由主线实际验证后传入；本程序不配置 WiFi、SoftAP 或路由。待验证的热点候选地址不能视为连接成功。

主线确认热点参数后，可在原启动命令中将目标换成已确认的机器人地址，添加 `--direct --host-key-alias 10.10.218.121`，省略旧校园源绑定，或换成已确认的热点本机源地址。网关安全路径白名单、默认120秒进程寿命（显式`--gateway-duration-seconds`可选1..600秒）、250ms命令期限均不变。此前实际 Accepted 仅证明中立/仅 Shift 包，非零方向链路仍未验。

先松开原始控制键，点击“取得策略会话”，等待原始回中包确认，再实际按 WASD / 方向键 + Shift。虚拟键位需显式切换来源。相反方向键原样交给核心；不能用映射后零值代替原始回中。10 秒租约到期后需重新点击取得。Space / 停止按钮锁存策略停止；清除锁存不会自动取会话。失焦、隐藏、切换与退出立即清键及撤销候选显示并尝试 release；网络不可用时依靠网关独立时钟推进到期。

候选值是网关策略数学输出，不是实际速度。actuator_attached 与 motion_enabled 必须一直为 false。示例 .25/.6 和 250ms 并非 M4 真实执行参数。

HTTP 只绑定 loopback，固定 Host、同源 Origin、CSRF token、精确 JSON 字段与长度边界。没有任意命令或路径接口。服务复用 dashboard 的固定 SSH/ProxyCommand 选项，仅跳板绑定指定源 IPv4；远端尾部替换为校验后的 ASCII 绝对网关路径和固定时限。主机身份验证不放宽。

GET /api/session 为每个窗口分配独立 controller_id/token，服务最多保留 32 个窗口身份（重启服务清空），不是 M6 完整身份认证。自己的 token 无法给其他窗口续命令或释放；任一授权窗口可以策略停止。启动后仅自动发送一次真正只读 request/status，要求 ACK RTT ≤250ms；按发送单调时刻与该 ACK 源 elapsed 建立固定时钟锚，不重锚延寿。后续源状态相对时效上界达到250ms即失效：不显示候选、拒绝命令、前端清键撤销采集，但保持同一 SSH 读取。只有源时间追上原锚后，新状态才能再次有效；不会自动重新取得会话。

持续读取 API2，每行最多 8192 字节；严格枚举/字段/类型、uint64 字符串、有限候选值、状态序号与时间单调校验。相同 elapsed 帧不延长新鲜时间。超过2秒没有源时间接收进度才关闭挂死 SSH（首次连接预算30秒）；EOF、协议异常和 ACK 错误仍关闭连接，不自动重连。请求包装为服务自增 request ID；周期 ID=0 不作为 ACK。串行事务、有界 ACK 队列及 .5 秒截止时间，超时关闭连接。浏览器携带实际观察的 elapsed/state_sequence，服务核对曾提供的状态，原样传 ISSUED 并只加 250 得到 EXPIRES，不能重打时间延寿。

浏览器约 50ms 获取状态及续命令，每次仅一条采样在途；代次、会话、序号、本机时效阻止旧包恢复显示。真实键变化立即撤销候选并取消旧请求。仅记录上述控制键的临时按下集合，不采集全局文字或上传文本。物理按键、租约到期、失焦/断线行为须用户实际观察；不得用合成输入或历史回放当作验收。

有效 arm/Accepted ACK 也是浏览器真实观察到的状态。经 boot/session、命令与状态序号、输入代次校验后，采用其中原始 elapsed/state_sequence，并以本次 HTTP 往返时长作为 ACK 年龄上界；不以 PC 时间改写 issued，也不让相同 elapsed 延长进度。后续当前实际按键可在 ACK 后按最少50ms发送间隔补发，仍只允许一个采样在途。输入变化、失焦或会话撤销后旧 ACK 不会被采用。原始 JSON 默认折叠，展开后固定340px滚动容器；候选、状态文字及按键区预留固定高度，采集状态变化不自动滚动或聚焦。

候选失效统一显示灰色“暂无有效候选值”，不在多个失效文案之间切换；原因保留在状态说明、候选 title 及可访问说明中。仅通过全部校验且仍新鲜的 Accepted ACK 候选显示绿色。相同可见文本不重复写入 DOM；原始键变化、失焦、过期仍立即撤销候选，不保留旧数值，不放宽200/250ms限制。本次只完成页面静态修正与语法检查，热点会话尚不能证明真实控制通过，待主线真实联调。


连续新鲜状态约1秒才允许手动取会话；任何失效仍立即撤销意图，不延长200/250ms期限。原始控制键展示独立于提交集合，失效不反复抹掉已观察按键；失焦/隐藏标记观察未知，不恢复旧键。后端错误按纯文字显示，断开与临时过期区分。2026-11-02经真实学校中转和Jetson进行20秒只读浏览器观察：181次采样中165次源状态有效且年龄低于200ms，0 POST、0脚本错误；仍有链路过期，不能算控制验收通过。
