## 修正的问题

- ROS可选构建缺前缀：构建器显式使用已存在的ROS/工作区和Python2，不修改系统或原厂源码。
- 项目采集二进制默认组可写，被自身信任检查拒绝：构建后设置当前用户专有执行权限。
- Python3缺Pillow：项目内固定Python2解码适配复用已有Pillow5.1，保留大小/身份/完整解码检查及子进程超时，不安装系统包。
- 相机安全策略未允许Blob图片：本机面板与访问代理仅在图片来源策略增加blob:；浏览器现检查真实图片而非仅接口200。
- 相机原程序默认一分钟退出：保留旧有限采集用法，项目管理入口使用明确--continuous和启动/卡读看门狗。
- 来源异常退出被清理流程覆盖为stopped：管理服务保留error及退出码；明确手动stop另行清除。
- OpenSSL默认配置目录不存在：支持本次显式配置和相邻安装配置，不更改全局环境。
- 访问代理遗漏/api/panel白名单：补齐正常页面依赖，默认只读仍裁掉令牌与动作。

相机曾出现一次原有V4L2 select timeout，后续直接读取与最终持续检查正常；未改驱动，也不声称该硬件/启动波动已根治。错误状态保留且无自动重启，长期稳定性继续待验。
